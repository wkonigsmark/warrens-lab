What's built, what's next, and every idea on the board.

A living document — we add to it as we workshop new ideas.

🧪 Latest update

Mission Quiz UI just shipped, joining the recently-landed Geocode mode. Both are working end-to-end but tagged Needs testing — they need real playthroughs to surface edge cases and tune the game feel (timing, scoring, mode-switching, mid-round exits, view changes, click spam).

Also landed: Roadmap overlay, full-page body scroll fix, hook-race fix in the quiz engine, and cache busting on script/style tags so dev edits show up on reload.

Built

  • Atlas data backbone — Famous 20 countries + 7 continents pulled from REST Countries and hand-curated with flag colors, motifs, climates, landmarks, foods, fact cards. Refresh anytime via node data/build_atlas.mjs.
  • Country-level interactive map — 212 country paths from Natural Earth GeoJSON. Famous 20 highlighted, the rest dim for context. Click any Famous 20 country to open its info modal.
  • Quiz engine — mode-agnostic, config-driven session driver. Same engine powers Mission and Geocode. Exposes geometry helpers (haversine distance, compass bearing, warmth bands).
  • Geocode mode (the "Guess Who + Globle" hybrid) 🧪 Needs testing — 14 hint categories, attribute-deduction gameplay, Globle-style distance + direction feedback on wrong guesses, warm/cold map breadcrumbs, full side-panel UI, win modal with country facts. Playtest priorities: mode-switching mid-round, hint-budget exhaustion, give-up flow, exit + return.
  • Mission Quiz UI 🧪 Needs testing — engine-driven "Locate Country" quiz. HUD strip with round counter, target announcement, score chip, End button. Wrong guesses get distance toast + warm/cold breadcrumb. Right guesses auto-advance. 10-round default, session-end summary with round-by-round attempts. Playtest priorities: auto-advance timing (currently 1.1s — too fast/slow?), exit mid-mission, summary X vs New Mission flow, switching Continents/Countries/Oceans views during a mission, click spam during the celebration window.
  • Roadmap overlay — this very surface. Living document of what's built, what's next, and every idea on the board. Wired to a toolbar button + ESC to close.

Build next (queued)

  • Print pipeline + first worksheet — pure-CSS @media print stylesheet that emits a Famous 20 trading-card deck. Doubles as the physical Geocode game board. The first proof that every digital mode has a pen-and-paper counterpart.
  • Atlas expansion — bump from 20 → ~50 countries so Geocode has real legs. Obvious adds: Indonesia, Turkey, Iran, Vietnam, Thailand, Pakistan, Poland, Sweden, Ukraine, Kenya, Ethiopia, Morocco, Chile, Colombia, Peru, plus more headline European and Asian states.

Game modes (ideated)

  • Geocode difficulty ladder — five scaffolded levels:
    • L1 Continent Decoder (ages 6-8): mystery is one of 7 continents.
    • L2 Famous 20 (current proof-of-concept).
    • L3 Regional Master: one region at a time (e.g. all of Europe).
    • L4 World Tour: all ~195 countries.
    • L5 Daily Mystery: one puzzle per day, same for everyone, shareable.
  • Where in the World (Daily Mystery) — Wordle-style. Five clues revealed one at a time ("Indian Ocean coast… Portuguese-speaking… capital starts with M…"). One puzzle per day, shareable result strip. Hooks casual visitors.
  • Flag Lab — flag literacy in deliberate passes: shape & color families → symbolism → match-to-country → draw your own on a printable proportion grid.
  • Compare Mode / Projection Lab — drag two countries side by side at true scale. Built-in Mercator distortion lesson (the Greenland-vs-Africa reveal).
  • Border Chains — given a start and end country, build the shortest chain of bordering countries between them. Teaches adjacency intuitively.
  • Multi-round Geocode streak mode — back-to-back mysteries with a running streak counter and shrinking hint budget.

Curriculum spine

  • Curriculum Atlas — a tree of modules, each a tight three-act loop:
    • Discover: narrated globe tour with cinematic camera moves.
    • Practice: in-app quiz drawn from the engine.
    • Take-Home: printable worksheet pack for pen-and-paper work.
  • Passport stamps — earned per module, stored in localStorage. A printable passport booklet that mirrors the digital one — kid fills it out alongside the on-screen version.
  • Age-tier paths — visual + reading-level variants so an 8-year-old and a 12-year-old can both use the same module appropriately.

Worksheets & print

  • Trading-card decks per difficulty level — also the physical Geocode game boards (digital + physical share the same data).
  • Trace / Label / Recall blank maps — three difficulty tiers per region. Trace = bold outlines + faded names. Label = blank shapes + word bank. Recall = blank shapes only.
  • Flag-coloring templates with proportion guides — kid draws their own.
  • Lat/long plotting grids — find this coordinate, mark the spot.
  • Border-coloring exercises — "color every country that borders France."
  • Cut-and-paste continent puzzles — physical jigsaws from our SVG paths.
  • Two-player printable Geocode board — 24 country tiles in classic Guess Who layout. Pencils to cross off eliminated tiles.
  • Solo detective sheet — single-page case file with scratch-off / cover-up clues.
  • Daily mystery printable — one-page handout for classroom use.
  • Passport booklet — physical companion to the digital passport stamps.

Polish & quality-of-life

  • Auto-zoom on guess — frame the action when a guess is far. The OrbisCountries.viewBoxOf() helper is already built and unused.
  • Warm/cold halo on guessed countries — color the whole country, not just a centroid dot, with intensity by proximity.
  • Hint cost variance — continent hint costs 2, "famous food" costs 0.5. Adds real strategy.
  • Disabled Give Up button after a round ends.
  • Snappier reveal animations on clue cards and chip-to-clue transitions.
  • Label cleanup in dense Europe — FR/ES/DE/IT/GB labels stack. Skip labels at this zoom or only show when a region is focused.
  • True centroids for crescent-shaped countries — Saudi Arabia's label currently sits inside Egypt due to bbox-center placement.
  • Continent color tint on Famous 20 — group countries visually by continent, matching the cinematic style.
  • Nav button wrap on narrower viewports — toolbar crowds below ~1100px.
  • Compact status header — the current "PLANET EARTH" status block eats ~150px of vertical space.
  • Persisted progress — save Geocode wins, played mysteries, and curriculum stamps to localStorage.
