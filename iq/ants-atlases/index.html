🗺 Latest update

Shape Match shipped — game + print worksheet. A new 🗺 Shape Match identifies a country from its outline silhouette. It's mechanically identical to Flag Match (same 8-rung ladder, smarter distractors, streaks, level-up, localStorage progress) but shows the country's shape instead of its flag. Shapes are rendered live from the Natural Earth geometry via a new AACountries.silhouette() helper that clusters polygons — dropping far-flung outliers (French Guiana on France, Alaska/Hawaii on the US) so the main landmass fills the frame, while keeping nearby islands so archipelagos (Japan, Indonesia, NZ, the Philippines) stay recognizable. A matching 🗺 Shapes of the World print worksheet (numbered black silhouettes → country names, difficulty selector, shuffle, upside-down answer key) ships alongside.

Earlier: 🏴 Flag Match game + 🏴 Flags of the World print worksheet (real flagcdn images, not emoji), the 🐘 Animals of the World sheet, atlas growth to 129 curated countries, and the rebrand from "Orbis" to Ants & Atlases. Fixed flag images being cropped (object-fit: contain).

Also new: 🚩 Build Your Own Country — an open-ended creative print sheet (no answers) where the kid invents a country: design a flag, draw the shape, name the capital, invent a national animal/food, and more. A keepsake, not a test.

Next: more fun print formats (Mystery Country Detective, Word Search, Dot-to-Dot, Flag Coloring), matching sheets (Foods, Landmarks, Capitals), and the Tier 4 curation runway.

Built

  • Atlas data backbone (196 sovereign nations · L1-L4) — REST Countries bulk fetch (/v3.1/independent?status=true) with a Taiwan backfill from /alpha. Hand-curated soft fields for tiers 1-3: flag colors, flag motifs, climate band, terrain headline, landmark, famous food, fact card, bordering waters, island flag. Tier 4 (116 countries) auto-populated with null soft fields. Each country tagged with a level (1-4). Refresh via node data/build_atlas.mjs. Atlas fetch is cache: "no-store" so data edits show immediately.
  • Atlas Data Table modal — 📊 toolbar button opens a sortable, searchable, level-filterable table of every country. Empty cells highlight in red so curation gaps for Tier 4 are obvious. Stats: 74 fully curated · 6 partial · 116 sparse. "Show only countries with gaps" toggle surfaces uncurated countries. The runway for incremental Tier 4 manual curation.
  • Tier ladder + picker (L1-L4 live) — chip bar above the map. Pool spec {type:'level', value:N} returns all countries with level ≤ N. Selection persists to localStorage. Mission and Geocode read the active tier. Map highlight re-renders instantly on tier change — out-of-pool countries dim to context. Region Focus zoom is preserved across tier switches. The hint engine returns noData responses (which don't consume budget) for L4 picks lacking curated soft fields.
  • Country-level interactive map — 212 country paths rendered from Natural Earth GeoJSON. Click any in-pool country to open its info modal. Dim countries are visible context but non-interactive.
  • Quiz engine — mode-agnostic, config-driven session driver. Pool specs: all, continent, iso2s, level, predicate. Same engine powers Mission and Geocode. Geometry helpers (haversine distance, compass bearing, warmth bands). Hint builders handle missing soft data via noData responses. Hook-race fix: autoStart: false + manual first-round call so controllers can stash the session reference before onRoundStart fires.
  • Geocode mode (Guess Who + Globle hybrid) 🧪 Needs testing — 14 hint categories (continent, language, flag colors, flag motifs, climate, hemisphere, capital letter, neighbors, water, size, population, terrain, landmark, food). Attribute-deduction gameplay. Globle-style distance + direction feedback on every wrong guess. Warm/cold map breadcrumbs accumulate. Side-panel UI with hint deck, clue log, guess log. Win modal with country facts.
  • Mission Quiz UI 🧪 Needs testing — engine-driven "Locate Country" quiz. HUD strip with round counter, target announcement, score chip, End button. Wrong guesses → distance toast + warm/cold breadcrumb. Right guesses auto-advance after 1.1s. 10-round default. Session-end summary with round-by-round attempt counts. HOME + NEW MISSION buttons. Country ISO labels hidden during a Mission (anti-cheat).
  • Flag Match game — multiple-choice flag identification with a combined 8-rung difficulty ladder (Starter → World Master). Each rung ramps the country pool (L1 → L4) and the choice count (2 → 6) together. Real flag images from flagcdn.com (the atlas flag_svg field), not emoji. Smarter distractors as you climb: random decoys at low rungs, same-continent decoys at high rungs. Streak counter, per-level "Level Up!" celebration, locked/unlocked rungs, localStorage progress persistence. Standalone flag-match.html in the cinematic dark theme, linked from the main nav.
  • Shape Match game — same engine and 8-rung ladder as Flag Match, but identifies a country from its outline silhouette. Shapes rendered live from Natural Earth geometry via AACountries.silhouette(), which clusters polygons to drop distant outliers (French Guiana, Alaska/Hawaii) while keeping archipelagos (Japan, Indonesia, NZ, Philippines) intact. Clean cutout silhouette on the dark card. Standalone shape-match.html.

Game modes (ideated)

  • Geocode difficulty ladder — five scaffolded levels:
    • L1 Continent Decoder (ages 6-8): mystery is one of 7 continents.
    • L2 Famous 20 (current proof-of-concept).
    • L3 Regional Master: one region at a time (e.g. all of Europe).
    • L4 World Tour: all ~195 countries.
    • L5 Daily Mystery: one puzzle per day, same for everyone, shareable.
  • Where in the World (Daily Mystery) — Wordle-style. Five clues revealed one at a time ("Indian Ocean coast… Portuguese-speaking… capital starts with M…"). One puzzle per day, shareable result strip. Hooks casual visitors.
  • Flag Lab — flag literacy in deliberate passes: shape & color families → symbolism → match-to-country → draw your own on a printable proportion grid.
  • Compare Mode / Projection Lab — drag two countries side by side at true scale. Built-in Mercator distortion lesson (the Greenland-vs-Africa reveal).
  • Border Chains — given a start and end country, build the shortest chain of bordering countries between them. Teaches adjacency intuitively.
  • Multi-round Geocode streak mode — back-to-back mysteries with a running streak counter and shrinking hint budget.

Curriculum spine

  • Curriculum Atlas — a tree of modules, each a tight three-act loop:
    • Discover: narrated globe tour with cinematic camera moves.
    • Practice: in-app quiz drawn from the engine.
    • Take-Home: printable worksheet pack for pen-and-paper work.
  • Passport stamps — earned per module, stored in localStorage. A printable passport booklet that mirrors the digital one — kid fills it out alongside the on-screen version.
  • Age-tier paths — visual + reading-level variants so an 8-year-old and a 12-year-old can both use the same module appropriately.

Worksheets & print

  • Trading-card decks per difficulty level — also the physical Geocode game boards (digital + physical share the same data).
  • Trace / Label / Recall blank maps — three difficulty tiers per region. Trace = bold outlines + faded names. Label = blank shapes + word bank. Recall = blank shapes only.
  • Flag-coloring templates with proportion guides — kid draws their own.
  • Lat/long plotting grids — find this coordinate, mark the spot.
  • Border-coloring exercises — "color every country that borders France."
  • Cut-and-paste continent puzzles — physical jigsaws from our SVG paths.
  • Two-player printable Geocode board — 24 country tiles in classic Guess Who layout. Pencils to cross off eliminated tiles.
  • Solo detective sheet — single-page case file with scratch-off / cover-up clues.
  • Daily mystery printable — one-page handout for classroom use.
  • Passport booklet — physical companion to the digital passport stamps.

Polish & quality-of-life

  • Inverse-scale country labels on zoom — labels currently grow proportionally with the zoom level. At Europe zoom (7×), GB/FR/DE labels look comically large. Apply a counter-scale so labels stay a consistent rendered size at any zoom.
  • Auto-zoom to the Mission target's region on round start (optional difficulty toggle) — using AACountries.viewBoxOfContinent() the engine could narrow the search area. Hides too much of the world for L2 but valuable for L3+ (Regional Master).
  • Frame breadcrumb cluster in Geocode — as wrong guesses accumulate, auto-zoom to fit the breadcrumb spread so the warmer/colder pattern is visible at a glance.
  • Warm/cold halo on guessed countries — color the whole country, not just a centroid dot, with intensity by proximity.
  • Hint cost variance in Geocode — continent hint costs 2, "famous food" costs 0.5. Adds real strategy.
  • Disabled Give Up button in Geocode after a round ends.
  • Snappier reveal animations on clue cards and chip-to-clue transitions.
  • True centroids for crescent-shaped countries — Saudi Arabia's label currently sits inside Egypt due to bbox-center placement.
  • Continent color tint on Famous 20 — group countries visually by continent, matching the cinematic style.
  • Nav button responsive wrap — toolbar still crowds on narrower viewports (below ~1100px). Either wrap cleanly or collapse into a menu.
  • Persisted progress — save Geocode wins, Mission scores, played mysteries, and curriculum stamps to localStorage. Show a daily streak.
