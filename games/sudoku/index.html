How It Works

Small Grid, Big Logic

Every row, column, and thick box needs each number exactly once. Start with 4x4, then move up to 6x6 and 9x9 when the pattern feels natural.

Beginner puzzles leave more starting numbers. Hard puzzles remove more numbers, and the generator checks that each puzzle still has one solution.
